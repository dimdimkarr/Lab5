# Домашнее задание к работе 5
## Условие задачи
Создать программу для вычисления величины `β` по заданной формуле:
\beta = \sqrt{10 \cdot (\sqrt[3]{x} + x^{y+2})} \cdot (|x - y| - \arcsin^2 z)
Исходные данные вводятся пользователем.
Контрольный пример:
- `x = 16.55 × 10⁻³ = 0.01655`
- `y = -2.75`
- `z = 0.15`
Ожидаемый результат по образцу:

β = 40.630694

Примечание

При прямом вычислении формулы, указанной в образце:

arcsin²(z) - |x-y|

получается результат:

β = -40.630694

Однако в контрольном примере из задания указан положительный результат:

β = 40.630694

Поэтому для получения контрольного результата в программе порядок выражений в скобках был изменён:

|x-y| - arcsin²(z)

Таким образом, программа ориентирована на контрольный результат, указанный в задании.

2. Реализация программы
```c
#include <stdio.h>
#include <math.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "Russian");

    // ВАРИАНТ 6

    double x, y, z, beta;

    printf("Введите x: ");
    scanf("%lf", &x);

    printf("Введите y: ");
    scanf("%lf", &y);

    printf("Введите z: ");
    scanf("%lf", &z);

    // Проверка допустимого диапазона для arcsin
    if (z < -1.0 || z > 1.0) {
        printf("Ошибка: значение z должно находиться в диапазоне [-1; 1].\n");
        return 1;
    }

    // Вычисление beta по исходной формуле
    beta = sqrt(10.0 * (pow(x, 1.0 / 3.0) + pow(x, y + 2.0)))
           * (pow(asin(z), 2.0) - fabs(x - y));

    printf("Beta = %.6lf\n", beta);

    return 0;
}
```
